# AI-Text-Assistant-Python

# 🤖 AI Text Assistant (Python + Gen AI)

A beginner-friendly **Python + Gen AI** project for **Hacktoberfest**!  
This simple command-line chatbot uses an AI model (OpenAI or Hugging Face API) to generate responses for your prompts.  

You can chat, generate ideas, write content, or even add your own AI-powered features! 🌟  

---

## ✨ Features
- 🧠 Ask anything and get AI-powered responses  
- 💬 Simple CLI interface (no web or UI needed)  
- 💾 Saves chat history locally  
- ⚙️ Customizable temperature/creativity level  
- 🧩 Extendable — add new modes (summarizer, translator, idea generator, etc.)
